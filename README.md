Agentic AI Demos

A collection of hands-on demonstrations, experiments, and educational notebooks exploring modern Agentic AI systems, agent orchestration frameworks, and AI-powered workflows.

This repository serves as a practical learning environment for understanding how autonomous AI systems are designed, connected, coordinated, and evaluated using current industry tools and frameworks.

Purpose

The goal of this repository is to provide working examples of:

- Agentic AI workflows
- Multi-agent systems
- Tool calling and function calling
- Shared state management
- Planning and reasoning systems
- Retrieval-Augmented Generation (RAG)
- MCP (Model Context Protocol) integrations
- Workflow orchestration
- Agent memory architectures
- AI observability and debugging

The notebooks in this repository are intended for both educational demonstrations and personal exploration of emerging Agentic AI technologies.

Current Notebook

langgraph_demo.ipynb

An introductory demonstration of LangGraph concepts including:

- Graph-based agent orchestration
- State management
- Shared context between nodes
- Conditional routing
- Multi-step reasoning workflows
- Agent execution flow

This notebook serves as a foundation for understanding how modern agent frameworks coordinate actions, tools, and decision-making processes.

Learning Objectives

This repository focuses on understanding:

1. What makes an AI system "agentic."
2. How agents plan and execute tasks.
3. How tools are integrated into AI workflows.
4. How state and memory are maintained across interactions.
5. The differences between LangChain, LangGraph, CrewAI, and other agent frameworks.
6. How MCP enables standardized tool integration.
7. How complex workflows can be orchestrated using graph-based architectures.

Why Agentic AI?

Traditional LLM applications generate responses.

Agentic AI systems can:

- Plan
- Reason
- Use tools
- Maintain state
- Retrieve information
- Coordinate multiple steps
- Adapt based on outcomes

Understanding these capabilities is becoming increasingly important as AI systems move beyond simple chat interfaces into autonomous and semi-autonomous workflows.
